Local Patient Records

Offline-first prototype · stored on this device

Unlock your records

Create a strong app password the first time. It encrypts the database on this device and is also needed for encrypted backups.

If you forget this password and have no usable backup, your records cannot be recovered.

Prototype warning: test with fictional patients first. This is not certified clinical software. Records are encrypted in this app's browser storage, but the phone's browser profile and device must also be secured.

Encrypted backup

Export a password-encrypted file and save it somewhere secure, such as an encrypted USB drive or trusted private storage. Keep the backup password separately.

Restore backup

Restoring replaces the current database. Export a backup of your current data first if you need to keep it.
